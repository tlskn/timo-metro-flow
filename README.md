## Установка и запуск ПР2

Проверенная среда — Python 3.14.8. Для ПР3 scikit-learn 1.9.1; остальные версии закреплены в requirements.txt. В зависимости от платформы для этих версий Python может потребоваться совместимая версия интерпретатора.

```console
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe scripts/split_batches.py
.venv\Scripts\python.exe src/metro_flow/eda.py
```

После активации окружения вместо `.venv\Scripts\python.exe` можно писать `python`. В Linux и macOS путь — `.venv/bin/python`.

В data/raw сохранены исходные выгрузки data.mos.ru. Скрипт разбиения создаёт исходную часть из 4009 строк и четыре полугодовые порции; контрольные суммы записаны в data/manifest.csv. Скрипт EDA записывает статистику в reports/eda_stats.json и рисунки в reports/figures. Схемы C4 и UML — diagrams/pr2; их исходники на Python находятся рядом с изображениями.

## Запуск ПР3

Из корня репозитория:

```console
.venv\Scripts\python.exe pr3/train.py
.venv\Scripts\python.exe pr3/prepare.py pr3/data/initial.csv pr3/features.csv
.venv\Scripts\python.exe pr3/prepare.py data/incoming/batch_01.csv pr3/batch_features.csv --history pr3/data/initial.csv
```

Тренировка сравнивает 27 конфигураций, включая сезонный ориентир, по четырём временным фолдам. Отложенный тест и новые порции при выборе модели не оцениваются. Пример подготовки batch_01 только строит признаки с историей и не является оценкой качества на этой порции.

Результаты — pr3/reports/experiments.csv и folds.csv, модель — pr3/models/model_v1.joblib, описание — model_v1.json. Копия pr3/data/initial.csv совпадает с data/initial/passenger_flow_initial.csv по SHA-256; дублирование сохранено для запуска исходных скриптов без изменений.

Выбрана Ridge short 10: WAPE на валидации 11,741%, сезонный ориентир 12,457%. Относительное улучшение около 5,75%; целевые 15% пока не достигнуты. Полный Ridge 10 используется отдельно для анализа коэффициентов; coefficients.csv относится к нему. Подробности протокола, ограничений и будущих работ приведены в отчёте ПР3.

Joblib содержит преобразования числовых и категориальных признаков и регрессор. Календарные лаги и исключение служебных пар выполняются в prepare(), поэтому при прогнозировании требуются подготовленные признаки и история.

Повторный запуск записывает новые даты и время вычислений. Проверяйте `git diff` перед фиксацией таких изменений. Открывайте joblib только из доверенного источника.

Разбиение, EDA, сравнение моделей и оба примера подготовки признаков повторно выполнены в отдельной копии. Метрики выбранной Ridge short 10 и ещё 25 конфигураций совпали с сохранёнными. У KNN 15 обнаружено отличие WAPE примерно на 0,001908 процентного пункта; причина отдельно не установлена. Оно не меняет выбор модели. Исходная таблица не заменялась результатами проверки; подробные различия записаны в VERIFICATION.json. Модель после сохранения и загрузки даёт те же прогнозы. Время вычислений не является временем ответа API.
